## Problem / Motivation

This repository had no `LICENSE` file. `brand/LICENSE-BRAND.md` (pull request #1) already licensed the brand files under CC BY 4.0 and the brand scripts under MIT, both by owner decision (2026-10-15 and 2026-10-16), but:

- everything else (the profile, the documentation, and now the community files and templates) had no licence, which by default means nobody outside may reuse it;
- GitHub's licence detection reads the root `LICENSE` only, so the repository showed no licence, and the community profile counted it as missing (`"license": false`);
- `brand/LICENSE-BRAND.md` linked to CC BY 4.0 without carrying its terms, so a copy of the brand folder travelled without them.

On 2026-10-16 the owner chose "MIT + full CC BY 4.0 text": MIT for the repository's code and text, and the full CC BY 4.0 legal code inside `brand/LICENSE-BRAND.md`, as the Cassandra Collective's carries its CC BY-ND text.

## Implementation Approach

**Two licences, split by folder and file type.**

| Part | Licence | Where |
|---|---|---|
| Every file outside `brand/` (documentation, profile, community files, templates), and the Python scripts inside `brand/` (`brand/tools/`, the scripts in `brand/figures/` and in each `brand/candidates/` folder) | MIT | `LICENSE` |
| Every other file under `brand/`: marks, lockups, icons, banners, cards, colour and type specifications, chart styles, images, documents and VectorCraft sources in `brand/kit/`, `brand/candidates/`, `brand/decision/` and `brand/figures/` | CC BY 4.0 | `brand/LICENSE-BRAND.md` |

This matches the split `brand/LICENSE-BRAND.md` already states ("every image and document under `brand/` (except the scripts listed below)"), and extends MIT to the rest of the repository. `NOTICE` adds one rule the split needs: a file copied out of `brand/` (for example a banner from `brand/kit/web/` used by the profile) stays under CC BY 4.0 wherever it is.

**Exceptions** keep their own licences, listed in `NOTICE`:
- `CODE_OF_CONDUCT.md` is the Contributor Covenant 2.1, under CC BY 4.0, as its attribution says.
- The letterforms in the brand files are outlines of Space Grotesk and Space Mono, under the SIL Open Font License 1.1. No font software is distributed here (`brand/LICENSE-BRAND.md`, "Fonts").
- The legal code in `brand/LICENSE-BRAND.md` is Creative Commons' text, reproduced unmodified.

**Copyright holder: "SuperconducTED contributors".** The engine's `LICENSE` and `brand/LICENSE-BRAND.md` both name it, so all three agree. This differs from the Cassandra Collective, whose `NOTICE` names the owner personally: there one person wrote everything; here several students do, and without a contributor agreement each keeps the copyright in their own contribution, under the same licence.

**Inbound equals outbound.** A contribution is licensed under the terms of the part it changes: code and text under MIT, brand files under CC BY 4.0. Because CC BY 4.0 allows adaptation, the maintainers can change or rebuild a contributed brand file, so the Collective's reason for taking brand contributions under a different licence (its brand files are no-derivatives) does not arise here.

**The legal texts are verbatim.** GitHub detects a licence by matching `LICENSE` against its template, so `LICENSE` is the engine's file unchanged. The CC BY 4.0 legal code was fetched from `https://creativecommons.org/licenses/by/4.0/legalcode.txt` and inserted by a script that asserts the fenced block equals the fetched text (minus trailing newlines) after writing. Only the sentences above the fence are ours.

**Where licences apply in the organisation.** A `LICENSE` in `.github` is not an organisation default: GitHub carries only community health files over to other repositories. The engine keeps its own MIT `LICENSE`; superconducted-codesign has none and is unaffected.

## Design Decisions

| Decision | Alternatives | Why | Who |
|---|---|---|---|
| MIT for the repository's code and text | CC BY 4.0 for the prose and MIT for the scripts only | Same licence as the engine and the brand scripts; one licence for everything that is not a brand file | Owner, 2026-10-16 |
| The full CC BY 4.0 legal code in `brand/LICENSE-BRAND.md` | A link only | The terms travel with the files; the copy is the published text, unmodified | Owner, 2026-10-16 |
| Holder "SuperconducTED contributors" | The owner's name, as in the Collective | Matches the engine and `brand/LICENSE-BRAND.md`; several authors | Engineering, following the existing files |
| Additions only to `brand/LICENSE-BRAND.md` | Rewriting its header in the Collective's shape | Its text is the owner's approved wording from pull request #1 | Engineering |
| `NOTICE` names folders, not files | A list of every licensed file | The build adds files; a folder rule stays true as it does | Engineering |

**Recorded for the owner.** Neither licence settles trademark questions: CC BY 4.0 does not license trademark rights (its section 2(b)(2)), and MIT does not mention them. No trademark is registered. `brand/LICENSE-BRAND.md` already says that the marks imply no endorsement by IBM, the Qiskit project, TED or TED University.

## Verification

1. **MIT text.** `git hash-object LICENSE` gives `fc6762b8db11432b8d5a48d6a58d1c9559fe19e4`, the blob of `LICENSE` on the engine's `main`. Compared with GitHub's own template (`gh api licenses/mit --jq .body`, with `[year]` and `[fullname]` filled in) after collapsing whitespace, the two are identical, 169 words each, so GitHub's detector, which matches against that template, should report MIT.
2. **CC BY 4.0 legal code.** Fetched on 2026-10-16 (HTTP 200, 18,657 bytes, SHA-256 `9ba9550ad48438d0836ddab3da480b3b69ffa0aac7b7878b5a0039e7ab429411`, LF line endings, no byte order mark, two non-ASCII characters: a pair of curly quotes). The insertion script's round-trip assertion passed. `git diff` on `brand/LICENSE-BRAND.md` shows additions only.
3. **Dashes.** No em or en dash in `LICENSE`, `NOTICE`, this record, or the lines added to `brand/LICENSE-BRAND.md` and `README.md` (the legal code itself contains none).
4. **GitHub's detection, before merge.** The license endpoint reads the default branch only, so it cannot check a branch; step 1 is the substitute.
5. **After merge:** the About panel should show "MIT license"; `gh api repos/SuperconducTED/.github/license --jq .license.spdx_id` should answer `MIT`; the community profile's `files.license` should no longer be null.

**Not tested:** how GitHub labels a repository with two licences (it reports the one in `LICENSE`); whether the CC BY 4.0 terms would hold for these particular marks in any court.
